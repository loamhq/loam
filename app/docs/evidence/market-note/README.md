# The listing and Loam’s note

Autumn 1.0.3 and Read aloud 1.1.4 carry the shortest and longest of the six
reviews in the captured Market list. Chromium rendered the app against a
fixture broker using copies of those reviews, covers, declarations and
maker content. The fixture uses Sam as the maker and shows the listings
before installation.

The listing opens at the cover. The before and after views align the title
block so the first content below the maker is visible. The sheet opens
from that position. All captures use Latte.

The capture driver accepts reviewed entries in the same format as
`test/market-fixture.mjs` through `MARKET_NOTE_LISTINGS`. With that input
omitted it exercises the bundled Focus timer update. Set `MARKET_EVIDENCE`
to the output directory. `MARKET_LOOKS` defaults to `latte,autumn`.
