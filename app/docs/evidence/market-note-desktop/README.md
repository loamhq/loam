# Desktop Market listing actions

Read aloud shows the network and server warning both before and after
installation. The Installed status takes the same space as Install. Autumn
shows Get or Use according to its installation state. Selecting Loam’s note
opens the review in either state.

Chromium rendered the app at 1440 × 1000 in Latte at 90% interface size.
The fixture broker served Read aloud 1.1.4 and Autumn 1.0.3 with their
catalog reviews, covers and listing details, using Sam for the maker.
Each installed view follows a confirmed installation in that fixture.
The listing captures frame the title block for comparison.
