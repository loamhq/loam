# File pane surface

Chromium captured the running app with a synthetic broker and synthetic files.
The Comments & suggestions plugin ran against its seeded document server.
Each sheet shows before on the left and after on the right, with dark above
light. Desktop captures used a 1440 × 900 viewport and are scaled to 60% in
the sheets. Phone captures used a 390 × 932 viewport and are shown at 1:1.
