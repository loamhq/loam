# The share page's fonts

Copies of the app's own Latte fonts (`app/public/fonts/`, made by
`app/tools/fetch-fonts.js`): Figtree (a variable font, used here from 300 to
800) and Caprasimo. Both are under the SIL Open Font License 1.1. The share
page stands outside the app, so it carries the faces Loam's page draws with.
