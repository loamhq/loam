# Loam 0.2.42

## For your agent

- **Major · Everyone.** Agents can now include charts, diagrams, timelines, and visual explanations directly inside their replies, styled to match your active Loam theme and light or dark mode. Ask an agent to explain something visually or sketch a comparison, hover for tooltips, open **Expand** to inspect it larger, or choose **Save to Files** to keep a standalone copy.
- **Small · Everyone.** **Settings › Appearance › Size** now spans **60% to 200%** in 5% steps (also with `Ctrl`/`Cmd` + `−`/`+` on desktop), fills the full screen width cleanly at smaller sizes, and keeps chats, headers, and the composer comfortable to read and tap up to 200%. The default `100%` is slightly more compact (what `90%` was before); if you already saved a custom size, Loam translates it once on update so your screen stays the size you chose.
- **Behind the scenes.** Enabled plugin Python environments (including sleeping on-demand servers) are checked on update, boot, and wake and automatically rebuilt from their lockfile or requirements if broken or moved between machines, rolling back cleanly if a rebuild fails; any plugin server that fails to start is surfaced in `loam status` and the periodic health check. Also fixed a rare PTY exit race when hashing sign-in passwords.
