# Loam 0.2.4

Small fixes to what 0.2.3 brought, from walking it.

## Fixed

- **A plugin's picture shows in Settings › Plugins.** A plugin with an icon
  showed a broken image; one without an icon now shows its first letter.
- **A plugin's own settings read properly.** Each setting's description sits
  above its field. Before, a long description was squeezed into a narrow
  column and the section ran thousands of pixels tall, looking like an
  empty grey panel.
- **An agent's pictures keep their own shape** in a conversation, instead of
  sitting in a fixed box with blank space around a wide one.
- **No box around a sheet's heading when it opens.** Loam still moves focus
  there for screen readers, but no longer draws a focus outline on it.

## Updating

Update from Settings › Update, or type `loam update` in your server's
shell. Nothing to do by hand.
