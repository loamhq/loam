# Loam 0.2.13

## For your agent

- **Major · People who rely on their vault or agent files.** Loam keeps a
  version on this server every 15 minutes, so an earlier copy can be
  recovered after an accidental edit or deletion. Ask, “Can you find the
  earlier version of this file?” For a copy off the server, open
  Settings › Plugins › Git backup.
- **Major · People who run Loam or test apps on the same server.** Loam’s
  firewall keeps a test app from being reachable from the internet by
  accident. If you already run a firewall, Loam leaves it in place. Ask,
  “Can you check whether my test app is reachable from outside?”
- **Small · People choosing a plugin or hosting Loam.** The plugin
  install screen and README explain that agents and plugins can control
  the server Loam runs on. Open a plugin’s install card in Settings ›
  Market to see the notice before deciding.
- **Small · People who add passkeys on a staging copy.** Adding one now
  opens that copy’s sign-in page. Try adding it in Settings › Account.
- **Small · People who download folders with large files.** In Files,
  open a folder’s menu and choose Download. On older engines a file over
  50 MiB is left out and named inside the ZIP, so the rest downloads.
- **Small · People who install plugins by link.** You can paste a GitHub
  link to a file inside a plugin’s repository into Settings › Plugins ›
  Install from link. Loam finds the plugin it belongs to.
- **Behind the scenes.** Updates start new timers and remove retired
  ones, conversation records use the right vault folder, and local
  Git backup status catches up after a push.

## Developer details

The built-in firewall allows inbound SSH, HTTP and HTTPS. To allow another
port, set `firewall.open` in `/etc/loam/loam.toml` and run
`sudo /home/loam/loam/bin/gen-deploy` on a standard install. Updates were
walked from 0.2.0 and 0.2.6.

If you skipped 0.2.12, it added off-server Git backup, folder ZIP downloads
and plugin install from a GitHub link. It also pinned provider CLIs to the
Loam release, retired Remote Control in favor of the Loam app, improved
message ordering and used the connected GitHub identity for agents’ commits.
