# Loam 0.1.0

The first release: Loam as one repository that installs on a fresh server
with one command.

- **Install and claim.** `install.sh` runs eleven steps, can be run again at
  any time, and ends with a one-time link that makes the person the owner.
- **Iris** is the agent every install starts with, with a hello thread.
- **Three providers**: Claude Code, Codex and Antigravity, each signed in to
  the person's own account in the browser, with their own memory features
  kept off so an agent's memory is its files.
- **Updates.** `loam update` moves the install to a newer release and puts
  the previous one back if a step fails; it never touches the person's own
  files, agents or plugins.
- **Plugins**: the reviewer (on) and daily notes (off) ship first-party;
  anything else is the person's own, under their plugins folder.

Version 0.x: the shape of the files and the interfaces may still change
between releases, and each release's notes say what moved.
