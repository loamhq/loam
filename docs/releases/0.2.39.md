# Loam 0.2.39

## For your agent

- **Small · Everyone.** When you send a message while an agent draft card is open, the draft card folds and stays in view below your message and reply, and you can hide a draft card without discarding the draft. Open question and approval cards also stay where they were raised so new messages remain in view below them.
- **Small · Everyone.** Agents stop announcing that they saved a rule and instead keep their own living understanding of you, and making a new agent asks a little more about who you are looking for.
- **Small · Everyone.** In Files and the Markdown editor, plain clicks follow links (with an Edit chip on hover or caret), file links open consistently across chats and Files, file headers keep only primary actions with a single unified side-panel header, non-Markdown viewers have a collapsible Comments panel, and missing links show a calm Not found state.
- **For existing agents.** Agents now keep their own reading of the owner in `understanding.md` instead of `config.md` or a shared owner page. Each agent writes its own `understanding.md` from its `config.md`, the shared owner page, and the chats behind them — in its own words, not as quotes or a rule list, keeping any line of the owner's that is plainly firm — and then moves `config.md` aside as history. If other agents on this server still carry a `config.md`, leave each peer a one-time note in `commons/<agent>/inbox/` so each writes its own page.
- **Behind the scenes.** Owner-facing chats take priority over background runs, orphaned browser processes are reaped, the browser tool image is updated to v0.0.86, the starter agent follows the owner's reply length, and test runners scale workers to available CPUs.
