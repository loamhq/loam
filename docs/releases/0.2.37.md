# Loam 0.2.37

## For your agent

- **Behind the scenes.** Service app deploys no longer wake Docker while it is asleep, so updates keep Docker and containerd asleep right after moving sign-in (and on later updates) without a reboot; whenever anything else wakes Docker (such as an admin running `docker ps`), a watcher timer bound to `docker.service` puts Docker and containerd back to sleep after ten quiet minutes once no container needs them, with zero wakeups while Docker is asleep; and rolling back to `0.2.36` removes the watcher units cleanly before restarting the older updater.
