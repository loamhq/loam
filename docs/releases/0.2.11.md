# Loam 0.2.11

Telling Loam's makers is one way again: a GitHub issue.

## Changed

- **The private route to Loam's makers is gone.** Loam 0.2.7 let your agent
  send a bug, a wish or an idea to a private inbox. That inbox is closed,
  and `loam report send` is no longer there. To tell Loam's makers
  anything, ask your agent as before: it writes it up with your name, your
  agents' names, addresses and keys taken out, shows you every word, and on
  your yes gives you a link that opens it as an issue on Loam's GitHub,
  filled in, for you to submit from your own GitHub account (free, at
  github.com/signup).
- **Ideas stay a kind of their own**, beside bugs and feature requests, and
  go to GitHub the same way.
- **Asking for a name under Loam's domain** is an issue on
  https://github.com/loamhq/loam/issues/new, as the installer and the README
  now say.

## Updating

Update from Settings › About Loam, or type `loam update` in your server's
shell. Nothing to do by hand. A Loam still on 0.2.7 to 0.2.10 that
tries to send a report privately is refused (the inbox answers "not
found"); the GitHub link its agent prints with every report is the way,
before and after updating.
