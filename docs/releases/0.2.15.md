# Loam 0.2.15

Syncthing 1.1.0 can connect to the service already running on your server.
Before you install or update the plugin, Loam shows which Syncthing settings
it will read. After you confirm, Loam saves the key in Settings › Connections › API keys,
where you can replace it. Loam checks again if the key is missing or Syncthing
rejects it. The plugin connects to Syncthing on this server.

Update Loam from Settings › About Loam or run `loam update` on your server.
