# Loam 0.2.31

## For your agent

- **Small · Everyone.** Theme-drawn agent faces (Latte art and signature theme icons) no longer let two agents share the same icon while the theme still has unused ones. Each agent gets a stable permanent slot stored on its record; existing agents keep their current face when unique, and only the newer agent moves when two were colliding. Uploaded agent pictures still win over theme faces.
- **Major · Everyone.** Files home is redesigned around **Your files**, **Recent**, **Pinned**, **Agent files**, **Loam files**, and Quick actions.
- **Behind the scenes.** Thread turns no longer fail when board folders migrate or encounter a stale API response.
