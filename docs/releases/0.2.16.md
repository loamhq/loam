# Loam 0.2.16

## For your agent

- **Major · People setting up Loam.** After connecting an AI provider,
  open the pinned Hello thread and its **Things to try** board. Explore at
  your own pace, ask for a tour, or ask your agent to save an idea for
  later. Try asking for a different theme. Your agent explains how to undo
  a change it makes and can save a short record of what you tried. On new
  installs, Hello is also where your agent can share relevant release news.
- **Major · People who keep notes and plans in threads.** Open a thread's
  board to see its cards. Choose **Add a note** to capture something, or
  **Open in Files** to edit the whole Markdown document. Use Back to go
  back to the board. On desktop, each panel has its own Back and Forward
  history. If two people edit a board at once, Loam flags the stale save
  so it can preserve the newer edit.
- **Small · People who manage their server or run several agents.** Open
  **Activity** from the desktop sidebar or the top of phone Settings.
  **Server resources** shows memory, CPU load, free space where the vault
  lives, and an estimate of how many more sessions the server can take.
- **Small · People installing Loam or setting up off-box backup.** The
  installer ends with the claim or sign-in instructions. To set up an
  off-box backup, open **Settings › Plugins › Git backup** when ready.
- **Major · People whose stock 0.2.13–0.2.15 update stops on generated app
  files.** The old updater checks those files before 0.2.16 can take over.
  If the refusal lists only the four generated files, ask your agent to
  help with the [one-time workaround](https://github.com/loamhq/loam/blob/0.2.16/docs/update.md#the-clean-tree-rule).
  The 0.2.16 updater accepts those files. Fresh installs can start on
  0.2.16 directly.
- **Behind the scenes.** Routine housekeeping clears stale Python bytecode.
