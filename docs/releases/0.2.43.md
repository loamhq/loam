# Loam 0.2.43

## For your agent

- **Small · People using Antigravity agents.** Agents running on Antigravity now reliably load their full persona instructions (even when those instructions pass Antigravity's per-file size limit) and see all shared Loam skills (including inline visuals), on both fresh and existing conversations. No action is needed: existing chats pick up the fix on their next reply.
- **Behind the scenes.** Antigravity persona instructions are rendered as split `trigger: always_on` rule parts under `.agents/rules/loam-persona-*.md` (removing the old single `loam-persona.md` on update), shared skill shelves are passed with `--add-dir` so out-of-workspace skill links resolve cleanly without duplicating owner-shadowed skills, `.agents` appears read-only beside `.claude` and `.codex` in agent spaces, and drift checks cover the new rule files.
