# Loam 0.2.0

The first public release. Since 0.1.0, the web app has moved into this
repository, an install has a sign-in page of its own, and documents can be
commented on and shared.

## New

- **The app is part of Loam.** The web app's code now lives in `app/` here,
  and an install runs it as a system service from a release of its own
  checkout, with no container. An update moves the app with everything else.
- **Loam's own sign-in page**, in front of the login service, with passkeys.
  Adding a passkey asks for a one-time code, and Loam hands that code to the
  owner in the app, so a server that sends no email can still register one.
  It offers no password reset it could not deliver.
- **Comments and suggestions on documents**, a first-party plugin. A
  Markdown note opens in an editor where you and your agents leave comments
  and suggested edits. A share link lets someone outside Loam read and
  comment without an account, and **Shared with me** opens documents
  shared from another Loam in your own editor. A table of contents follows you
  through a long document: ticks along the edge on a desktop, the current
  section in the bar on a phone. On a phone the share sheets rise from the
  bottom, and the whole editor follows Loam's themes, light and dark.
  It ships turned off and limited to a staging copy; to use it, turn it on
  in Settings › Plugins and set "Where the editor and share links work" to
  everywhere.
- **Bring your context from another AI.** Iris, the starter agent, can take
  an export from another assistant (a ZIP upload works) and turn it into
  notes, saying how much of it was covered.
- **A stuck engineer job shows as stuck**, and a command that never returns
  is stopped instead of holding the job forever.
- **The first day is smoother**: a new agent appears as a card, a failed turn
  reads as a plain line in the thread, update steps fold away, sign out and
  passkeys are in Settings, Files starts with useful shortcuts, and
  **Build an app with an agent** is one tap from Apps.
- **Appearance**: the Sun mode shifts colour gradually at its boundaries, at
  the speed you choose.

## Changed

- Agents' faces are initials and colours; the emoji face is retired.
- Replies point back to the words they answer, not to message numbers.
- A reply that finishes after you sent a new message is placed after it.
- No agent run has a memory ceiling any more. When the server runs short,
  Loam's own services are the last to be stopped.
- The installer creates the vault folders the system writes to and says
  what it is about to take.

## Fixed

- Archiving and restoring an agent update Chats at once.
- Provider names no longer break on a phone's welcome screen.
- A failed turn no longer names its model `<synthetic>`.
- A finished update says "Update finished", not "Loam is up to date", and
  shows no empty file list.
- Loam's background services come back after a reboot.
- Long file names wrap in their menu instead of running out of it.

## Moving from 0.1.0

`loam update` moves an install to this release and puts the previous one
back if a step fails; it never touches your agents, vault, threads or
plugins. `docs/update.md` says what an update installs and what it leaves to you.

Version 0.x: the shape of the files and the interfaces may still change
between releases, and each release's notes say what moved.
