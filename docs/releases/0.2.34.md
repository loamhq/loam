# Loam 0.2.34

## For your agent

- **Small · Everyone.** Open chats on phones now recover automatically when a screen locks or the tab goes to the background, so live progress and replies keep showing without refreshing the page.
- **Small · Everyone.** Files is tidier: new installs no longer place a `README.md` at the top of Your files (and updates remove untouched stock copies while leaving any copy you edited alone), and Loam's engineer docs and schedule page live quietly inside **Loam files** (`System/engineer/` and `System/schedule.md`) instead of `Projects/Loam/`.
- **Small · People on smaller servers.** Loam uses much less idle memory: the browser, Docker, and plugin servers sleep until first use, idle chats unload sooner without dropping arriving turns, built-in tool servers are lighter, memory admission scales to the server's RAM with automatic swap, and memory limit events are recorded durably (`loam limits`).
- **Small · People who share plugins.** `loam market share` now creates a missing GitHub repository automatically instead of asking the owner to make one by hand.
- **Behind the scenes.** Shipped agent docs, reviewer memory paths, and provider instructions were refreshed against current Loam, stale plugin-gateway and browser-proxy units reconcile cleanly on updates, and provisioning refreshes renamed agents' display names across Claude Code, Codex, Antigravity, and `schedule.md`.
