# Loam 0.2.2

Your agents can now get Loam itself changed on your own server, tell Loam's
makers about a problem, and find plugins other people made.

## New

- **Every install has an engineer.** The engineer is the part of Loam that
  changes code when an agent asks it to. Until now it existed only on the
  server Loam is developed on. Elsewhere, asking it for a change to Loam
  failed with "the engineer's own composition is broken". Now the installer
  sets it up, and updating to 0.2.2 sets it up on an install you already
  have. Its instructions are two notes in your vault, under
  `Projects/Loam/engineer/`, and they are yours to read and change. A later
  update brings them up to date only if you haven't changed them. If you
  have, your version is kept.
- **Changes to Loam on your server are kept across updates.** A change the
  engineer makes to Loam stays on your server. It isn't sent anywhere. Each
  update then fits the new release around it. If a release changes the same
  lines, the update stops before changing anything and your agent asks you
  what to do. Nothing of yours is thrown away without your word. Wherever a
  plugin can do the job, your agents will make a plugin instead, because
  updates never touch plugins.
- **Tell Loam's makers about a bug or an idea.** Your agent writes the
  report and takes out personal details: names, addresses, paths, keys and
  note names. It shows you every word before anything goes. If you say yes,
  it gives you a link that opens the report on GitHub, ready to submit from
  your own account. If your engineer fixed the problem on your server, the
  fix can go along with the report.
- **A marketplace for plugins**, in Settings › Plugins: themes and
  extensions other people have shared, each with a Get button. Loam reads
  the list from `loamhq/marketplace` on GitHub, which is public. It's empty
  for now. Your agents can also share a plugin you made, from a GitHub
  repository of yours, and ask for it to be listed. Every listing is
  checked by hand before it appears.

## Fixed

- **The engineer can no longer write over conversation records on any
  install.** That protection named the folder by the name it has on the
  first install, so on other installs it didn't apply.
- **The engineer can edit plugins in your plugins folder** with its normal
  editing tools. Before, it could only reach them through its shell.

## Updating

Update from Settings › Update, or type `loam update` in your server's
shell. After the update, your agent can ask the engineer for a change to
Loam straight away.
