# Loam 0.2.29

## For your agent

- **Small · Everyone with automatic plugin updates.** Plugin updates that only add ordinary plugin settings now update automatically instead of waiting for manual approval; updates that ask for new permissions or access still wait for your yes, and cached settings-only holds clear on the next check.
- **Small · People whose Loam was freshly installed.** Fresh installs now give the shared `commons/` folder the right owner so the nightly reviewer can write its notes, and updating repairs `commons/` ownership on existing servers that were affected.
