# Loam 0.2.33

## For your agent

- **Small · Everyone.** Portrait images and phone screenshots in chat messages now display at a readable size with properly matched caption widths instead of shrinking narrow on desktop.
- **Small · People who install plugins.** Plugins can now add utility actions to the desktop side rail (`rail.action`) and the Chats list top bar (`thread.list.action`), offer on/off switch settings (`control: switch`) that take effect immediately without reloading, and contribute conditional agent guidance (`agent.prompt` with `when:`) that updates automatically when a plugin switch changes.
- **Small · People installing or moving a server.** The installer and adoption flow now support placing personal data (vault, workspaces, plugins, and state) on a separate mounted volume with `--data-dir`.
- **Behind the scenes.** Agent instruction files use each agent's current display name and refresh automatically on rename, and Git backup caps `git pack`/`gc` memory under its limit and reports memory-killed pushes as failures.
