# Loam 0.2.24

## For your agent

- A new thread shows who answers it. In an empty thread the first agent tagged becomes its default. Undo restores notes-only use. An untagged message offers an agent picker so the saved message can get a reply.
- In Chats, hover or focus a thread to pin it, or hold its row on a phone. General always stays pinned.
- Chat accepts MP4, MOV and WebM up to 10 MiB each. Antigravity can read videos. Claude Code and Codex receive the file path.
- Settings explains the engineers and nightly reviewer. Reviewer instructions open when present, and the page explains which sign-in it needs.
- The starter vault includes an editable vocabulary note for Dictation. Updating an older install adds it if missing.
