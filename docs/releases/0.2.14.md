# Loam 0.2.14

## For your agent

- **Major · People who install plugins from the Market or a link.** Those
  plugins can now update automatically. Open Settings › About Loam to
  change the default or review an update that asks for more access. Open
  a plugin in Settings › Plugins to see where it came from or turn its
  automatic updates off. Editing an installed plugin pauses its updates.
- **Small · People who customise plugins.** You can keep a separate copy
  that takes precedence over the original. Ask, “Can you make me a copy
  of this plugin to customise?”
- **Small · People choosing a Market plugin.** Open its listing in
  Settings › Market to read Loam’s review beside the install button,
  when a review is available.
- **Small · People who read or edit files in Loam.** Open a document in
  Files. The viewer and editor now match the rest of the app.
- **Small · People starting a conversation or setting up Loam.** Start a
  new thread to use a provider you have connected. On a fresh install,
  Hello offers a few ways to get started.
- **Small · People who send messages while an agent is busy.** Keep
  writing in the same thread. Loam does a better job keeping messages
  in order and recovering a conversation after an interruption.
- **Small · People who manage several Hetzner Cloud projects.** The
  built-in plugin can use a separate key for each named project. Open
  Settings › Connections › API keys › Hetzner Cloud › Project keys.

## Developer details

Activity keeps a record of automatic plugin updates. The session API and
the service that runs providers can now restart independently,
so a web API restart can leave the provider running.
