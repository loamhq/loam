# Loam 0.2.1

Fixes for what a walk through a fresh 0.2.0 install found broken.

## Fixed

- **`loam update` works from the root shell.** Typing just `loam update`
  now checks for a newer release and offers to install it. Before, it was
  an error. If you run it as root, which is the shell you installed from,
  it switches to Loam's own user first. That means it no longer reports
  "not a git checkout" and no longer leaves files owned by root behind.
- **An update notice can no longer repeat forever.** On 0.2.0, running the
  update as root could leave a notice that Loam couldn't clear. It was then
  posted in General, and gave your agent a turn, every 30 seconds. Now a
  notice is delivered once, and the same line isn't posted to the same
  agent twice within an hour. If a notice can't be cleared, Loam says so
  once, in its log, with the command that fixes it.
- **Adding a passkey no longer signs you out of the open tab.** The sign-in
  service renews your session when you add a passkey. One request from the
  app could catch the moment and come back unsigned, and the tab then said
  "Your session has ended" although it hadn't. The app now checks again, for a few seconds,
  before it decides. If your session really has ended, the page now looks
  like Loam's sign-in.
- **Comments & suggestions works once you turn it on.** Before, it only
  worked on a staging copy, and the plugin page had no way to change that.
  Turning it on now turns it on everywhere. Any plugin's own settings now
  show on its page in Settings › Plugins.
- **"Build an app" no longer leaves an empty chat behind.** If you leave a
  new thread without writing anything, it is deleted instead of staying in
  Recent.
- **Providers counts only what you can connect.** "0 of 5 connected" became
  "0 of 3": the ones marked "Coming later" aren't counted.
- **An agent tagging another agent wakes them.** When an agent posts with
  its thread tool and tags another member (for example "@Iris …"), that
  agent now gets a turn, just as when you tag them. The limit on turns
  between agents still applies. The post also shows in an open thread
  straight away, without a reload.

## If you ran `loam update` as root on 0.2.0

Some of the update's files may be owned by root, and General may be
getting the same notice over and over. As root, run:

    chown -R loam: ~loam/.local/state/loam/update

Then update from Settings › Update. From 0.2.1 on, `loam update` as root
fixes this by itself.
