# Loam 0.2.3

Your API keys have one home, and your agents can show you pictures.

## New

- **Settings › Accounts holds your API keys.** OpenAI, Google (Gemini),
  Hetzner, and any other service a plugin needs: you enter each key once,
  and every plugin that uses that service uses it. Loam checks a key with
  the service before keeping it, and nobody can read one back, not the page
  and not your agents. A plugin can be given a different key of its own,
  from the same page. Your agents can save a key for you when you hand them
  one.
- **A plugin says which keys it uses before you install it**, beside what
  else it reaches, and it is given those keys and no others. Read aloud and
  Dictation now use your Google key from Accounts. If you had set a Gemini
  key on your server before, it is still used, and Accounts shows it as set
  on this server.
- **Images, a plugin for making pictures.** Your agents make and change
  images with OpenAI's or Google's image models, whichever key you have, and
  each is saved in your vault as an ordinary file, in an Images folder. It
  will be in the marketplace; it is not installed by itself.
- **Your agents can show you images in a conversation.** An agent's reply
  can carry up to three pictures, under its words, as your own attachments
  are shown. Tap one to see it full size; swipe or use the arrows for the
  next.

## Changed

- **Loam itself no longer makes images.** The image tool moved into the
  Images plugin, so an install only makes images, and pays for them, when
  you choose to.
- **A plugin is no longer handed a key it didn't ask for.** Before, a plugin
  could be given any key in your server's own settings file by its name.

## Updating

Update from Settings › Update, or type `loam update` in your server's
shell. Nothing to do by hand. To let your agents make images, install
Images when it is listed, and add an OpenAI or a Google key in
Settings › Accounts.
