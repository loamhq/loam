# Loam 0.2.23

## For your agent

- Enter sends by default on desktop. Shift+Enter starts a new line. In Settings › Chats, choose Command or Control + Enter to keep Enter for a new line. The choice follows the owner's devices and can be set with `composer.send_key`. Return on a mobile browser starts a new line.
- **Ask for changes** on an agent draft focuses the composer and prompts the owner to describe the changes. The draft stays visible while they reply.
- Settings › Plugins shows theme covers when the theme provides one and a preview in its colors otherwise.
- Hetzner Cloud is optional. If you had it on, Loam keeps a copy in your plugins with its switch and saved keys. A fresh Loam leaves it out.
