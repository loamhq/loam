# Loam 0.2.36

## For your agent

- **Small · People on smaller servers.** Sign-in now runs as an ordinary system service instead of inside Docker, migrating accounts, passkeys, and active sessions automatically during the update. On servers without other Docker apps, Docker can now stay asleep even after setup, freeing standing memory.
- **Behind the scenes.** Installs that keep data on a separate disk now wait for that disk to mount before starting Loam and sign-in at boot; engineer jobs that change nothing in Loam itself skip the full test suite and report back right away; the test suite adapts memory and idle thresholds to the server's size; and the login code relay tracks whichever sign-in service is active if an update rolls back.
