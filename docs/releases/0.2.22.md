## For your agent

- Claiming starts the owner's first day. General starts empty and health notices begin with current checks. People who already claimed their Loam keep their conversations and board entries.

- Stock installs set up the nightly reviewer and the server settings checked overnight. Generated Python bytecode can stay in the checkout during an update.
