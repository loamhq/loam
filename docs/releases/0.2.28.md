# Loam 0.2.28

## For your agent

- **Major · Everyone.** Boards is no longer part of Loam. Updating removes the built-in Board button, card editor, and board expiry jobs; any existing board notes in your vault stay untouched as ordinary Markdown notes in Files.
- **Major · Everyone.** Loam’s own notices and health findings always go to the agent chosen in **Settings**, never to a board. That agent decides whether to act on a finding, message the owner, or note it somewhere.
- **Major · Everyone.** Messages no longer get stuck sending; one that can’t go shows **Not sent yet** with **Retry**.
- **Small · People with plugins that add thread header controls.** Returning to a thread reserves space for its contributed header controls so the thread title does not jump while plugins load, and plugin page modules load faster.
- **Small · People with local or link-installed plugins.** A built or link copy of a plugin that matches an older tag of a listed repository is adopted from the Market so it can receive Market updates.
- **Behind the scenes.** Extensions can contribute per-thread Markdown files and thread header views; agent-creation cards stay in thread history; renamed agents keep their current name across Files and provider instructions; and scheduled identity checks work reliably across providers.
