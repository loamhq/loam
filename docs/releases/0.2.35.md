# Loam 0.2.35

## For your agent

- **Small · People who install plugins.** The `chat.draft` command now accepts an optional `agent`, so plugins can open a new thread with a pre-filled, editable draft either addressed to a specific agent or left open for you to pick one. Multi-line pre-filled drafts size to fit on open, place the caret inside the trailing empty line, and keep focus and scroll position when the new thread is created.
- **Behind the scenes.** Loam updates now re-exec the new updater after moving the checkout, guard post-apply notices cleanly, and heal stale running records; idle sessions that retry a turn after being unloaded record `turn_retried` limit events; and the shared persona text notes that Files is the space shared with the owner.
