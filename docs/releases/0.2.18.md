# Loam 0.2.18

## For your agent

- **Major · People setting up Loam for the first time.** After connecting
  an AI provider, open the unread Hello on a phone or read the thread that
  opens on desktop. Iris greets you by name and shows what Chats, Files
  and Apps are for. Tell her something about yourself and ask her to
  remember it in About me, or start with whatever you came to do. If
  you already set up Iris, your greeting and Iris's existing setup stay
  as they are.
- **Small · People on an install with the new Hello.** Board, Details,
  Branch, Activity, Settings and the desktop's Hide list have labels
  until you use them. Empty boards, folders and the Apps list explain
  what goes there. Chats, Files and Apps keep their names in the tab bar.
- **Small · People who move between chats, files and agent profiles.**
  On desktop, click a file link in a chat to read it beside the chat.
  The side panel's three-dot menu contains Reload and Open. Back stays
  within the active tab and follows the history of the list or panel
  you're using. If you opened an agent's workspace file from its
  profile, Back takes you to that profile.
- **Small · People making a new agent with Iris.** Start in Hello
  or Settings › Agents › New agent. Iris asks what you're looking for
  and waits for your answer before drafting.
- **Small · People installing Loam.** The installer shows progress as
  each step runs. You can use the install command on Debian 13 and
  Ubuntu 26.04 as well as Debian 12 and Ubuntu 24.04.
- **Behind the scenes.** Agents read the same workspace inputs across
  providers, thread handoffs run privately and yield to new messages,
  Claude Code's local slash-command output stays out of chat turns,
  updates refresh reviewer instructions, and gated shared-checkout
  landings use the owner's Git identity.
