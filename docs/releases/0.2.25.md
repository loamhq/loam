# Loam 0.2.25

## For your agent

- Chats accept MP4, MOV and WebM up to 512 MB each. Choose a file, drop it or paste it. The composer shows progress, lets you cancel and keeps your draft if the upload fails.
- The original plays in the thread when the browser supports the codec and stays in the vault. Antigravity gets a smaller viewing copy for large clips. Claude Code and Codex receive the original file path.
