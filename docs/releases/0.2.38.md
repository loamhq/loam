# Loam 0.2.38

## For your agent

- **Small · Everyone.** Loam now keeps a local, numbers-only record of server health and resource use (memory, CPU, disk space, active chats, background runs, owner services and sites, and limit or restart events — never messages, files, or agent names). By default everything stays on this server and nothing is sent out; **Settings › About Loam** now shows a **Usage data** line confirming whether usage counts stay on this server only or are sent to a configured collector host.
- **Behind the scenes.** Service restarts on Python 3.13 / Debian 13 servers now shut down cleanly in a second or two instead of waiting out the shutdown backstop across `session-broker`, `session-host`, and `plugin-gateway`; `session-host` cold starts skip re-parsing full journals for sessions whose catalog fields are already saved; lock directories created by root helpers are handed back to the install user instead of blocking later runs; plugin contribution errors are logged instead of failing silently; and separate data disks work cleanly when `paths.root` uses a custom directory name under home.
