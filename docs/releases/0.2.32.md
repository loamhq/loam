# Loam 0.2.32

## For your agent

- **Major · Everyone.** Sharing any file and Comments & suggestions are now two separate built-in plugins: share any vault file with a password-protected link under **Files › Shared** (with an inline PDF viewer and clean view-only share pages), and leave whole-file comments or anchored Markdown comments and suggestions on any file.
- **Small · Everyone.** Files home has roomier Places cards, one-line paths, and **Loam files** at the bottom; **Files › Recent** excludes board folders and shows accurate owner attribution.
- **Small · Everyone.** Browser-tool screenshots now stay attached in threads, and agents are told when an image cannot be kept.
- **Small · Everyone.** Wiki-links in chats render as clickable links again.
- **Behind the scenes.** Plugin timers stay intact across re-applies, sharing and comments HTTP responses handle connection teardown and concurrency more reliably, and test runs no longer leak into the live attention feed or touch live plugin units.
