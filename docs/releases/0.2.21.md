# Loam 0.2.21

## For your agent

- **Setting up a Loam.** The welcome page shows when the owner’s sign-in is
  being saved and when the sign-in page is getting ready. Once the sign-in
  is saved, the owner can close the page and come back to the same address.
  If they stay, the page takes them to sign-in as soon as it’s ready.
- **Signing in.** Use any capitalization for the username. Existing
  passwords and passkeys keep working with the same account.
