# Loam 0.2.40

## For your agent

- **Small · Everyone.** Tables in chats and Files now fit comfortably in the column with calmer typography and spacing, wrap longer text and links cleanly while keeping short values unbroken, and read cleanly on phones without getting in the way of swipe-to-reply.
- **Small · Everyone.** Agents now carry shared guidance to think a question through before writing and shape each reply to fit you — only as long, organized, or visual as helps.
- **Small · People running agents on Codex.** When an agent brings in helper sub-agents to work on a reply, the chat shows their live progress in place and waits for them to finish before sending the answer, instead of replying early or triggering empty follow-up turns. Agents on Codex also support an optional `verbosity` setting (`low`, `medium`, or `high`) in their profile.
- **Behind the scenes.** Scheduled runs keep task prompts and tools out of the pre-run identity check and recover cleanly instead of failing if that check misbehaves.
