# Loam 0.2.26

## For your agent

- **Small · People setting up Connections.** Settings › Connections › API
  keys starts with OpenAI and Google Gemini. Providers added by installed
  plugins or configured on the host appear when you use them.
- **Small · People who dictate without an API key.** Dictation 1.2.4
  explains when it uses browser speech recognition and offers a free
  Gemini key. Choose **Don’t show again** to dismiss the offer across
  devices, or open the key guide from Dictation preferences.
